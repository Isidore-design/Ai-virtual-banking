# AI-Monitored Virtual Banking System

A secure virtual banking platform that uses Artificial Intelligence to monitor transactions, detect fraud, and protect users in real-time.

## 🚀 What This Project Does
- Create a virtual bank account
- Send and receive money virtually
- View transaction history and balance
- AI monitors every transaction for suspicious activity
- AI flags fraud, unusual spending, and sends instant alerts

## 🧠 How The AI Works
- Learns normal spending behaviour of each user
- Detects unusual patterns: large transfers, strange locations, rapid transactions
- Scores each transaction as Safe, Suspicious, or Fraud
- Automatically blocks or flags high-risk transactions
- Sends alert to user and admin

## 🛠 Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python / Node.js
- Database: Firebase / MongoDB
- AI: Machine Learning for Fraud Detection
- Tools: GitHub, VS Code

## ✨ Key Features
- User Login & Signup
- Virtual Card & Account Number
- Real-time Balance Update
- Transaction History
- AI Fraud Detection Dashboard
- Admin Panel to Review Flagged Transactions

## 📸 How To Run It
1. Clone this repo
2. Open `index.html` in your browser
3. Create an account and try a transaction
